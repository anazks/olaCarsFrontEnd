# OlaCars User Manual: Table of Contents

This manual is structured around core business workflows, helping you understand how to navigate the application based on real-world processes.

## 7. Insurance Management

*   **7.1 Vehicle Policies**: Adding and renewing insurance policies for the fleet.

*Workflow for handling vehicle incidents.*
